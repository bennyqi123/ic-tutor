一、 课题背景与需求分析
集成电路（IC）产业作为国家战略核心，对人才的专业素质要求极高。然而，在实际的学习与培养过程中，学生普遍面临着显著的“断层”现象。首先是认知断层，初学者面对物理、化学、电路、工艺等交叉学科，难以构建清晰的知识脉络，容易陷入只见树木不见森林的困境；其次是效率断层，大量的实验报告撰写和基础文献阅读消耗了学生宝贵的精力，导致深度思考时间不足；最后是科研断层，前沿学术论文的晦涩术语与复杂的工艺参数，构成了从本科理论到科研实践的高耸门槛。
针对上述痛点，本项目旨在利用生成式人工智能技术，构建一个垂直于 IC 领域的智能辅助系统，为学生提供从入门规划、课程学习到科研实践的全流程支持，实现个性化、高效化的专业成长。
二、 核心功能与设计思路
本项目突破了传统“问答式”AI 的局限，将大模型能力与结构化的工程工具相结合，设计了四大核心功能模块：
可视化的学习路径规划： 系统能够根据用户的当前状态（如大一/大三）和职业目标，动态生成定制化的学习计划。利用 Graphviz 绘图引擎，将离散的知识点转化为层级分明的依赖关系图谱，直观展示先修课程与进阶技能的逻辑联系，有效降低新生的认知负荷。
实验数据自动化处理： 针对理工科高频的实验场景，设计了标准化的报告生成工作流。系统可接收非结构化的原始实验数据，结合实验原理库，自动生成包含数据分析、图表建议及误差探讨的完整报告草稿，显著提升学习效率。
文献参数智能提取： 面向科研场景，利用 PDF 解析工具与大模型的长文本理解能力，能够从英文文献中精准提取关键工艺参数（如栅长、阈值电压、功耗等）及核心创新点，并以结构化表格呈现，辅助学生快速建立对特定工艺节点的量化认知。
深度专业问答： 集成 DeepSeek 大模型接口，预设了工艺原理、故障分析等专业 Prompt，能够提供比通用搜索更精准、更具逻辑性的学科知识解答。
三、 技术实现与创新优势
本项目采用“大模型 + 工具链”的轻量化技术架构。后端接入 DeepSeek API 作为核心推理引擎，利用其在理工科逻辑推理方面的优势处理复杂任务；前端基于 Streamlit 框架构建，实现了响应式的 Web 交互界面与云端部署，确保了系统的易用性与可访问性。
项目的核心创新在于“思维的可视化”与“垂直场景的深度封装”。不同于通用的 AI 聊天工具，本项目通过 Prompt Engineering 将隐性的思维过程转化为显性的知识图谱，实现了“所想即所见”。同时，通过对实验和科研场景的专门优化，成功将大模型能力转化为实际的生产力工具，不仅解决了学生当下的作业痛点，更为长期的专业素养培养提供了有力支撑，具有极高的推广价值与应用前景。

研究初衷（一些碎碎念）：作为一名大一新生，我最大的感受就是“迷茫”。集成电路这个学科门槛太高了，知识体系庞杂，从物理到工艺，从设计到制造，每一块都很难啃。我们往往不知道从哪里下手，也不知道现在的学习和未来的芯片设计有什么关系。另一方面，我们在做实验时，往往陷入机械记录数据的重复劳动，写报告时却不知道如何深入分析；而当我们想尝试接触科研，打开一篇 IEEE 论文，密密麻麻的英文术语和参数更是让人望而却步。
为了打破这些壁垒，我利用 DeepSeek 大模型的 API，结合 Streamlit 搭建了这样一个一站式的辅助平台。它不是一个简单的聊天机器人，而是集成了学习规划、实验辅助和科研加速的全能助手。
首先是解决“迷茫”的问题。针对像我一样的新生，我开发了“学习路径生成”功能。我们不需要去网上翻阅零散的经验贴，只需要输入现在的年级和想要从事的方向，比如“模拟 IC 设计”，系统就会基于行业大模型的数据，推理出一条完整的成长路线。更重要的是，它会将这些抽象的课程转化为可视化的知识图谱，让我们直观地看到，要学好运放设计，必须先打好电路分析的基础。这种全局观的建立，对新生来说至关重要。
其次是解决“作业与实验”的痛点。我们日常有大量的实验报告要写，但很多时候时间都花在了调整格式和罗列数据上。在“实验报告生成”模块，我实现了一个高效的工作流：只要输入原始的实验数据和简单的现象描述，系统就能迅速生成一份结构完整的报告草稿，包含原理分析、数据表格甚至误差来源探讨。这并不是为了偷懒，而是将我们从重复性劳动中解放出来，让我们有更多精力去思考数据背后的物理意义。
最后是针对科研入门的“论文速读”功能。集成电路领域的论文通常包含复杂的工艺参数。通过上传 PDF，这个智能体能够自动提取出我们最关心的核心指标，比如工艺节点、供电电压、增益带宽积等，并整理成表格。这对于我们快速筛选文献、理解前沿技术参数有着巨大的帮助。
在技术实现上，整个项目完全由我个人独立开发。后端接入了 DeepSeek 大模型强大的语言理解能力，前端使用 Python 的 Streamlit 框架实现了轻量化的 Web 部署。目前，这个平台已经上线，任何同学通过浏览器都能随时访问。
我希望“IC 芯手村”能成为我们同学的“外挂”，帮助大家在探索中国芯的道路上，少走弯路，学得更深、更远。
